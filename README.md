# Lane-Keep-Assistance_ClassicAutosar_Fusa
Lane Keep Assistance Project is a personal project to sharpen my Classic AUTOSAR skills and demonstrate my Classic AUTOSAR skills.  
Since all AUTOSAR projects follow the ASPICE V Cycle, the same shall be done here.  

![ASPICE V cycle](https://www.suse.com/c/wp-content/uploads/2020/12/aspice-process-reference-model-groups-edit-1024x631.png)

Phases of the project shall include:  
Phase 1: Define Customer Requirements (SYS.1).  
Phase 2: Define System Requirements (SYS.2).  
Phase 3: Define System Architecture (SYS.3).  
Phase 4: Define Software Requirements (SWE.1).  
Phase 5: Define Software Architecture (SWE.2).  
Phase 6: Implement Functional Safety.  


Rest things shall come along.
